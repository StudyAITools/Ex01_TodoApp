# 할 일 (TODO 앱)

빌드 도구도 외부 라이브러리도 없는 바닐라 JavaScript TODO 앱입니다.
목록은 브라우저의 `localStorage`에 자동 저장됩니다.

## 실행

```bash
npm start            # → http://localhost:3000
PORT=4000 npm start  # 다른 포트로 실행
```

> ES 모듈을 쓰기 때문에 `index.html`을 파일로 바로 열면(`file://`) 동작하지 않습니다.
> 반드시 위 명령처럼 로컬 서버로 여세요. (`python3 -m http.server -d public` 같은 다른 정적 서버도 됩니다.)

## 테스트

```bash
npm test
```

Node 내장 테스트 러너(`node --test`)로 상태 로직, 저장소 처리, 정적 서버(경로 탈출 차단 포함)를 검사합니다.

## 기능

- 할 일 추가 · 완료 체크 · 수정 · 삭제
- 필터: 전체 / 진행 중 / 완료 (URL 해시 `#/active` 등에 반영되어 새로고침·뒤로 가기에도 유지)
- 모두 완료/해제, 완료 항목 한 번에 삭제
- 삭제 **실행 취소** (6초 안에 토스트에서, 원래 위치로 복원)
- 진행률 표시, 탭 제목에 남은 개수 표시
- 여러 탭을 열어 두면 서로 자동 동기화
- 다크 모드, 모바일 화면 대응
- 키보드·스크린리더 접근성 (항목이 사라질 때 포커스 이동, 변경 사항 음성 안내)
- 한글 IME 입력 시 Enter로 항목이 두 번 추가되는 문제 없음

## 사용법

| 동작 | 방법 |
| --- | --- |
| 추가 | 입력 후 <kbd>Enter</kbd> 또는 **추가** 버튼 |
| 완료 표시 | 왼쪽 동그라미 클릭 (키보드: <kbd>Space</kbd>) |
| 수정 | 제목 더블클릭 또는 ✎ 버튼 → <kbd>Enter</kbd> 저장, <kbd>Esc</kbd> 취소, 바깥을 누르면 저장 |
| 삭제 | 🗑 버튼 → 잠시 뜨는 **실행 취소**로 되돌리기 |

수정할 때 제목을 모두 지우고 저장하면, 실수로 보고 원래 제목을 유지합니다. 지우려면 삭제 버튼을 쓰세요.

## 구조

```
Ex01_TodoApp/
├── public/              # 브라우저에 제공되는 파일
│   ├── index.html
│   ├── styles.css
│   └── js/
│       ├── todos.js     # 상태 로직 (순수 함수, DOM 의존 없음)
│       ├── storage.js   # localStorage 저장/불러오기 (실패해도 앱이 멈추지 않음)
│       └── app.js       # 렌더링 · 이벤트 · 포커스 관리
├── test/                # node --test 테스트
├── server.js            # 의존성 없는 정적 파일 서버
└── package.json
```

데이터는 `localStorage`의 `todo-app/v1` 키에 JSON으로 저장됩니다.
주소마다 따로 저장되므로 `localhost:3000`과 `127.0.0.1:3000`의 목록은 서로 다릅니다.
